        懂你注音

        會學習的注音輸入法，打越多越懂你。跟微軟注音一樣的打法，選字更準，打的字只在你的電腦上處理。

        先在網頁上試用 下載 Windows 版 免費・Windows 10／11・約 53 MB・MSI 安裝檔・程式碼簽章政策
        怎麼安裝？
        1. 下載後點兩下「DongNiZhuyin.msi」。如果出現「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。
        2. 詢問「是否允許變更」時按「是」。
        3. 裝好後登出 Windows 再登入一次（或重新開機），懂你注音會自動加進鍵盤清單。
        4. 按 Win＋空白鍵切換到「懂你注音」就能打字。
        5. 要移除：設定 → 應用程式 → 已安裝的應用程式 → DongNi Zhuyin → 解除安裝。你的學習紀錄會保留。

        速度只算打對的字。你打的內容只留在你的瀏覽器，不會傳到任何地方。
