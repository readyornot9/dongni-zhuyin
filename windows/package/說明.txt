懂你注音 Windows 版
====================

會學習的注音輸入法：打越多，越懂你。所有選字都在你的電腦上完成，打的字不會傳到任何地方。

【安裝】
1. 把整個「懂你注音」資料夾解壓縮出來（不要直接在壓縮檔裡執行）。
2. 點兩下「安裝.cmd」。
   - 如果出現「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。
   - 接著會詢問「是否允許變更」，請按「是」（註冊輸入法需要）。
3. 看到「安裝完成」後，按 Win＋空白鍵，切換到「懂你注音」。
4. 已經開著的程式（瀏覽器、LINE、Word…）要關掉重開才會出現。

安裝完就可以刪掉這個資料夾；以後要移除，再下載一次執行「移除.cmd」也可以。

【基本打法】（跟微軟注音一樣）
- 標準注音鍵盤。一個字打完按聲調鍵，一聲按空白鍵。
- 打錯的注音直接重按就換掉：ㄊㄨㄢ 再按 ㄍ → ㄍㄨㄢ。
- 打完一句按 Enter 送出；字打完後按空白鍵會送出並打一個空白。
- 改字：按 ← → 移到那個字，再按 ↓ 選；數字鍵 1～9 直接選。
- 單按 Shift 切換中／英。
- Shift＋符號鍵是半形（! @ # ? : " { }），Ctrl＋符號鍵是全形中文標點（，。？：、『』！（））。
- ` 鍵打開符號面板。

【學習】
你選過的字會記住，下次在同樣的前後文自動選對。學習紀錄存在 %APPDATA%\ShunDa，移除輸入法也會保留。

【需求】
Windows 10 或 11（64 位元）。安裝時需要系統管理員權限。
大約佔用 150 MB 硬碟空間、執行時約 200 MB 記憶體。

【移除】
點兩下「移除.cmd」。
